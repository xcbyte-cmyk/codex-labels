# 계정별 작업 창

`계정별 실행.cmd`를 실행하면 기존 로그인과 작업을 쓰는 **현재 계정 · 기본 프로필**이 목록에 먼저 표시되고 선택됩니다. 새 계정은 **새 계정 창 추가 → 선택한 창 열기**를 사용합니다. 기본 프로필은 표시용 항목이며 로그인 정보나 작업을 새 계정 폴더에 복사하지 않습니다. 계정별 창에서 선택기를 열면 그 창의 항목을 선택해 보여줍니다. 실제 로그인 이메일은 각 창의 계정 메뉴에서 확인하세요.
예: `회사 계정 A`, `개인 계정 B`. 창 이름은 구분용 별칭이며, 로그인한 이메일의 검증 결과가 아닙니다.
처음 연 창에서 사용할 ChatGPT 계정으로 직접 로그인하세요. 각 창의 계정 메뉴에서 실제 로그인 계정을 확인합니다.
같은 창을 다시 열면 기존 창으로 전달하고, 서로 다른 계정 창은 동시에 실행합니다.

## 분리 범위

- 각 창은 `accounts/<무작위 ID>/user-data`와 `codex-home`을 사용합니다.
- 로그인은 해당 `codex-home`의 파일 저장소를 사용하고 ChatGPT 로그인 방식을 지정합니다.
- 대화·설정·라벨·작업 지정·실행 상태는 계정 창별로 저장합니다.
- 부모 프로세스의 Codex 실행 주소, 로그인 토큰, OpenAI API 키를 계정 창에 전달하지 않습니다.
- 다른 계정으로 자동 전환하거나 자격 증명을 복사하는 코드는 없습니다. 할당량 제한은 Codex의 해당 로그인 계정에 적용됩니다.
- 앱 실행 파일은 하나를 공유합니다. 계정마다 수 GB의 앱 사본을 만들지 않습니다.

기존 `실행.cmd`와 기본 작업 목록은 유지됩니다. 기존 스레드·플러그인·원격 연결 설정을 새 계정 창으로 자동 복사하지 않습니다.
두 창에서 같은 ChatGPT 계정으로 로그인하면 같은 구독 할당량을 사용합니다. 서로 다른 창 자체가 새 할당량을 만들지는 않습니다.
계정 메뉴에서 의도적으로 다른 계정으로 다시 로그인하면 그 계정의 구독을 사용합니다. 별칭이 특정 이메일을 강제하는 기능은 아닙니다.

## 계정 창 삭제

계정 선택 창에서 대상을 선택한 뒤 **선택한 계정 삭제**를 누릅니다. 확인 창에 표시된 계정 이름을 확인하세요.
해당 창과 실행 중인 작업을 종료하고 `accounts/<ID>` 전체(로그인 토큰, 대화, 설정, 라벨, 브라우저 캐시, 플러그인 캐시, 진단 파일)를 삭제합니다.
백업·휴지통 사본을 만들지 않습니다. 다른 계정과 외부 작업 폴더, ChatGPT 계정·구독 자체는 삭제하지 않습니다.

삭제 전에 실제 프로세스의 계정 인자와 저장소 경로를 확인합니다. 오래된 상태 파일의 PID만 보고 프로세스를 종료하지 않습니다.
자료가 남거나 프로세스 종료가 실패하면 **삭제 미완료**로 표시하고 해당 계정의 실행을 막습니다. 같은 항목의 삭제 버튼으로 다시 시도하세요.
폴더가 사라진 것을 확인한 뒤 마지막 삭제 기록도 제거해야 완료로 표시합니다.
파일시스템에서의 삭제이며 디스크 보안 삭제나 클라우드 기록 삭제를 의미하지 않습니다. 공용 드라이버·Windows 기록은 삭제 대상이 아닙니다.

## 기타 제한

- 계정별 창의 Windows 알림 연결은 비활성화합니다. 공용 `codex-labels://`와 기존 알림 등록을 다른 계정으로 바꾸지 않습니다.
- 계정별 창에서는 업데이트 설치·재시작·롤백을 실행하지 않습니다. 계정 창을 모두 닫고 기본 설치 도구를 사용하세요.
- 기본 창과 계정 창은 같은 소스 폴더를 수정할 수 있습니다. 로그인 분리가 파일 수정 충돌을 방지하지는 않습니다.
- 이 기능은 로컬 계정 창 분리입니다. 원격 호스트를 나중에 연결하면 그 호스트의 로그인 계정이 적용되므로 별도로 확인해야 합니다.
- 실제 구독 사용 확인에는 각 계정의 사용자 로그인과 작업 실행 검증이 필요합니다. 로그인 화면이나 프로세스 시작만으로 실제 과금·할당량 사용을 검증했다고 보지 않습니다.

## 개발용 명령

```powershell
python windows_helper.py accounts --root '설치 폴더'
python windows_helper.py account-create --root '설치 폴더' --name '회사 A'
python windows_helper.py account-list --root '설치 폴더'
python windows_helper.py account-launch --root '설치 폴더' --account-id '생성된 ID'
python windows_helper.py account-delete --root '설치 폴더' --account-id '삭제할 ID' --confirm-delete
```

`accounts/`에는 비공개 인증·대화 데이터가 생성됩니다. 배포 ZIP과 Git에 포함하지 않습니다.
