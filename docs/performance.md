# 라벨 갱신 최적화와 검증

## 변경 범위

라벨 저장 형식과 설정창의 편집 기능은 유지하며, 설정 전달과 사이드바 갱신을 정리했다. 새 서버나 런타임 의존성은 추가하지 않았다.

- main의 디렉터리 감시가 변경을 감지하면 100ms 동안 알림을 합쳐 신뢰된 창에 변경 신호만 보낸다. 저장·할당 결과도 같은 캐시에 반영하고 다른 창에 알린다.
- `read(snapshotVersion)`은 변경이 없으면 `null`을 반환한다. 설정창의 `read()`는 전체 데이터를 반환한다. 버전은 설정 오류와 할당을 포함한 실제 데이터 변경 시에만 바뀐다.
- renderer의 1.5초 전체 조회를 변경 신호 구독으로 교체했다. 파일 감시 누락에 대비해 보이는 창에서 30초 간격으로 조건부 조회하며, 포커스 복귀와 숨김 해제 시에도 확인한다.
- 설정창과 배경 갱신의 읽기를 직렬화했다. 읽는 중 도착한 변경 신호는 후속 조회로 합치며, 저장 전에 시작된 오래된 응답은 적용하지 않는다.
- 전체 화면 감시는 행의 추가·제거를 찾는 용도로만 사용한다. 바뀐 부분의 하위 요소만 검사하고, 기존 행의 제목·식별자 변경은 행별 감시기로 처리한다. 채팅 변화마다 사이드바 전체를 탐색하지 않는다.
- 할당 변경은 해당 행만 갱신한다. 설정 변경은 필요한 행을 확인하되 배지 표시값이 같으면 DOM을 다시 쓰지 않는다. 행 제거와 페이지 종료 시 감시기, 변경 구독, 타이머를 정리한다.

## 같은 입력으로 비교한 결과

기준 버전은 `d96a9895f628a92d802e0cba808ef47d68022fde`이다. 실제 Chromium에서 가상 사이드바의 작업 20개를 표시한 후, 채팅 영역에 요소를 20번 추가했다. 각 추가 사이에는 프레임을 넘겨 배치로 합쳐지지 않게 했다. 초기 배지 표시는 측정에서 제외했다.

| 측정 대상 | 기준 버전 | 수정 후 |
| --- | ---: | ---: |
| 기존 행의 제목 TreeWalker 탐색 | 400회 | 0회 |
| DOM 쓰기가 발생한 서로 다른 기존 배지 | 20개 | 0개 |

이는 동일 입력에서 불필요한 행 탐색과 배지 쓰기를 제거했다는 근거다. 채팅 요소를 찾는 감시기 콜백 자체가 없어졌다는 뜻은 아니며, 실제 Codex의 CPU·메모리 사용량이나 실행 속도를 측정한 결과도 아니다.

## 회귀 검증

- Node 72개: 저장, 알림, 캐시, IPC. 조건부 조회, 같은 내용의 버전 유지, 설정 오류 복구, 다중 창 전달 경계, 변경 신호 병합과 구독 해제를 포함한다.
- Python 빌드 15개: 패키징 무결성, 실패 시 보존, 개인 설정 보존 등 기존 빌드 검증.
- Chromium 22개: 기존 알림 9개와 라벨 13개. 지정·해제, 프로젝트 식별자, 행 재사용·제목 교체·재부착, 사이드바 교체, 설정 충돌 시 편집 내용 보존, 동시 읽기·저장, 보조 조회와 종료 정리를 포함한다.

```powershell
node --test
python -m unittest discover -s tests -v
# Playwright와 Chromium이 설치된 테스트 환경에서:
$env:CODEX_LABELS_BROWSER_TESTS = '1'
python -m unittest discover -s tests -p 'test_*renderer.py' -v
```

브라우저 테스트는 `labels.example.json`과 가상 preload만 사용한다. 사용자 설정이나 실행 중인 Codex 앱에는 접근하지 않는다. `CODEX_LABELS_CHROMIUM`에 테스트 브라우저 실행 파일을 지정할 수 있다. 과거 소스와 비교하려면 `CODEX_LABELS_RENDERER_SOURCE`에 추출한 `renderer.js` 경로를 지정하고 `test_unrelated_chat_mutations_do_not_scan_or_repaint_rows`를 실행한다. 기준 버전에서는 0회 검증이 실패하는 것이 예상 결과다.

이번 변경은 실제 Windows 토스트 클릭이나 종료 상태에서의 알림 활성화를 검증하지 않는다. 기존 실행본에 적용하려면 수정된 소스로 실행본을 새로 준비해야 한다.
