Codex Labels 0.2.1 - Windows x64

처음 한 번
1. 이 PC에 공식 Codex를 설치합니다.
   지원 버전: Microsoft Store 26.911.7940.0 / 내부 앱 26.911.61220.
   다른 버전은 호환 여부를 확인한 새 패키지가 필요합니다.
2. ZIP을 계속 사용할 쓰기 가능한 폴더에 모두 압축 해제합니다.
   예: D:\Apps\CodexLabels. ZIP 안에서 바로 실행하지 마세요.
3. 설치.cmd를 더블클릭합니다. 진행 창에서 공식 앱의 사본을 준비하고 바로가기를 만든 뒤 Labels를 엽니다.
   약 3GB의 여유 공간이 필요합니다. Python, Git, Node.js는 설치하지 않아도 됩니다.
4. 실행.cmd 또는 바탕화면 Codex Labels 바로가기로 실행하고 이 PC에서 로그인합니다.

매번 사용할 때
- 바탕화면 바로가기를 더블클릭합니다. 설치는 매번 할 필요가 없습니다.
- 원본 Codex는 열어 두어도 됩니다. 다른 폴더의 Labels는 먼저 닫아 주세요.

업데이트
1. 라벨 설정 → Codex Labels 업데이트 → 업데이트 확인을 누릅니다.
2. 새 버전이 있으면 다운로드 및 다음 실행에 적용을 누릅니다.
3. 설치하고 다시 실행을 누르면 종료 대기 → 설치 → 앱 실행이 이어집니다. 열린 작업이 중단될 수 있으니 먼저 마무리하세요.
4. 라벨 설정과 작업 지정은 유지됩니다. 이전 실행본은 runtime/app.backup-날짜 폴더에 보관됩니다.
설치하고 다시 실행을 누르기 전에는 앱을 종료하지 않습니다. 진행 창에서 설치 상태를 확인하고 실패 시 다시 시도할 수 있습니다.
0.1.0에서 처음 업그레이드하거나 수동 설치할 때는 Labels를 닫고 새 ZIP을 기존 폴더에 풀어 설치.cmd를 실행합니다.

다른 PC로 옮길 때
- 이 ZIP을 옮겨 각 PC에서 따로 설치합니다. 만들어진 runtime 폴더나 로그인 프로필은 복사하지 마세요.
- 색상과 라벨 이름만 옮기려면 Labels를 닫고 labels.json을 복사하면 됩니다.
- 작업별 상태는 assignments.json에 있지만, 프로젝트 경로와 작업 ID가 다른 PC에서는 같지 않을 수 있습니다.
- 자동 설정 동기화는 제공하지 않습니다. 이 PC의 CODEX_HOME과 작업 저장소는 원본 Codex와 공유합니다.

이 패키지는 비공식 확장 도구입니다. 공식 Codex 바이너리, 로그인 정보, 개인 라벨 지정은 포함하지 않습니다.
설치 폴더를 이동했다면 설치.cmd를 다시 실행해야 합니다.
관리자 권한이나 PowerShell 실행 정책 변경은 요청하지 않습니다.
회사 정책 또는 Windows 보안이 실행을 차단한다면 차단을 해제하도록 시스템 설정을 바꾸지 말고 관리자에게 확인하세요.
알림/프로토콜 연결은 자동 등록하지 않습니다. Windows 알림 클릭 연결은 별도의 실험적 기능입니다.

소스와 버전 안내: https://github.com/xcbyte-cmyk/codex-labels
